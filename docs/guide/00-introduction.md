# 第 0 章: はじめに

このガイドへようこそ。

このサイトを 5 分読んで作業すれば、あなたの **「スプレッドシートの URL を投げるだけで AI が GAS を書いて実行する」環境** が立ち上がります。Web 版でもスマホ版でも、Claude Code を開いた瞬間からそのまま動きます。

必要なのはブラウザだけ。Node.js も clasp も認証ファイルのアップロードもいりません。

## このガイドでできるようになること

- スプレッドシートの URL を Claude Code に投げるだけで、自動で集計・転記・整形などの GAS が動く
- 「毎朝 9 時にこのタブを更新」「A 列が編集されたら B 列に日時を入れる」といった**トリガー設定まで自動化**
- 1 回セットアップすれば、**Web・スマホ・デスクトップのどの Claude Code からでも**同じ環境で作業できる
- GAS の書き換え履歴は GitHub に自動バックアップされる

## 新方式の最大メリット

### 1. インストール不要（ブラウザだけ）

セットアップは「GitHub でリポジトリを作る」「Apps Script をブラウザで Deploy する」だけ。PC に何かをインストールする手順はありません。

### 2. Web / スマホの Claude でも動く

毎セッションごとに認証ファイルをアップロードする必要がなくなったため、Claude のどのクライアントからでも完全に等価に動作します。外出先のスマホから発注シートを更新する、といった使い方が可能です。

### 3. 1 度 Dispatcher を Deploy したら以降ゼロ設定

窓口となる GAS（Dispatcher）を最初に一度だけ Deploy しておけば、あとは何台 PC を買い替えても、どのセッションで Claude Code を開いても、そのまま使えます。

## たとえ話：優秀なバックオフィス

あなたは部長です。部下（Claude Code）に仕事を頼むと、その部下は **会社の受付窓口（Dispatcher GAS）** に「この書類を処理しておいて」と依頼を出します。受付窓口はあなたの権限でファイル室（Google スプレッドシート / ドライブ）にアクセスし、依頼を処理します。

- **あなた**：指示する部長
- **Claude Code**：あなたの指示を仕事に落とし込む派遣エンジニア（Web / スマホ / デスクトップからも指示できる）
- **Dispatcher GAS**：全てのスプレッドシート依頼を中継する 1 つの窓口
- **GitHub（private）**：コードと認証情報を保管する鍵付き書庫

旧方式ではこの派遣エンジニアが毎回「会社の鍵」を持ち歩く必要がありましたが、新方式では **鍵は書庫に置きっぱなし** で、派遣エンジニアが自分で取りに行けるようになりました。
