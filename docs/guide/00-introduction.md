# 第0章: はじめに

このガイドへようこそ。

このサイトを 5 分読んで作業すれば、あなたの **「スプレッドシート URL を投げるだけで AI が GAS を書いて実行する」環境** が立ち上がります。Web 版でもスマホ版でも、Claude Code を開いた瞬間からそのまま動きます。

必要なのはブラウザだけ。Node.js も clasp も、PC への認証ファイル配布も要りません。

## 一言でいうと

::: tip 🏢 たとえ話: 優秀なバックオフィスを雇うようなもの
あなたの会社に **コードが書けて、Google スプレッドシートの細かい操作が得意で、24 時間いつでも動いてくれる新しいアシスタント** が入社したとします。

あなたがやることは、チャットで「このスプシのデータをこう集計して」と日本語で依頼するだけ。アシスタント（Claude Code）は、プログラム（GAS）を書いて、実行して、失敗したら自分で直して、作業履歴もきちんとファイリング（GitHub）してくれます。

このガイドは、そのアシスタントを **あなた専用に配属する** ための入社手続きマニュアルです。
:::

## このシステムで何ができるか

例えば、以下のような作業を **プロンプト 1 行** で依頼できます。

- 「このスプレッドシートの売上データを集計して、別シートに月別サマリーを書き出すGASを作って」
- 「毎朝 9 時に在庫データを更新する GAS を書いて、トリガーも設定して」
- 「既存の GAS でエラーが出てるから、ログ見て直して」
- 「スプシ A と B のデータを突合して、C シートに差分を書き込んで」

Claude Code が自動で:

1. シート構造を HTTP で読んで把握
2. GAS コードを書く
3. 対象シートのコンテナバインド GAS に保存、または使い捨てで実行
4. エラーが出たらログを見て修正
5. GitHub にコードをバックアップ

を一貫して行います。人間の作業は **「やりたいこと」を日本語で伝えるだけ** です。

## 旧ガイドから何が変わったか

このガイドは 2026 年 4 月の改訂で、 **窓口 GAS（Dispatcher）方式** に全面移行しました。

| 項目 | 旧（〜2026/03） | 新（現在） |
|---|---|---|
| 必要ツール | Node.js, clasp | **なし**（ブラウザのみ） |
| 認証方式 | `clasp login` → `.clasprc.json` をアップロード | 窓口 GAS を Deploy → URL + トークンをリポジトリにコミット |
| Claude Code の環境 | デスクトップ推奨（Web でも可） | **Web・スマホ・デスクトップ全て等価** |
| セットアップ時間 | 60〜90 分 | **5 分** |
| セッションごとの手間 | 認証ファイル再アップロード | **ゼロ**（clone した瞬間に環境変数展開） |

旧方式で既に構築済みの方は [付録 A: 旧 clasp 方式について](/appendix/legacy-clasp) に移行手順があります。

| スキルレベル | 所要時間 |

| PC 初心者・非エンジニア | **約 10 分** |
| IT 経験あり | **約 5 分** |

## 前提知識と用意するもの

### 必要な前提知識

- スプレッドシートの基本操作
- コピー & ペースト
- ブラウザで Web サイトを開ける

**プログラミングの知識は不要** です。このガイドでコードを書く場面はほぼありません。

### 用意するもの

- インターネットに接続されたブラウザ（PC / スマホ / タブレットどれでも）
- Google アカウント（業務用推奨）
- GitHub アカウント（無料）
- Claude（Anthropic）アカウント（Pro 以上のサブスクリプション）

**PC へのソフトインストールは一切不要** です。

### 料金について

必要なツールはほぼ全て無料枠で運用できます。発生するのは **Claude の月額サブスクリプション** のみ（Pro で $20/月〜、Max で $100〜）。詳細は [第 5 章: トラブル & FAQ](/guide/05-troubleshoot-faq#料金について) を参照。

## セキュリティについて（要点）

- 窓口 GAS の URL とトークンは **private リポジトリにコミット** します。**必ず private** にしてください
- 実行は **あなたの Google アカウントの権限** で走るので、他人の権限は混ざりません
- public 化したい場合は、事前に [付録 C: セキュリティ詳細](/appendix/security) のローテーション手順を実施
