# 第1章: 全体像

セットアップに入る前に **4 つの登場人物と、それらがどう連携するか** を 3 分で把握します。ここを理解しておくと、あとで詰まっても自分で切り分けられます。

## 4 つの登場人物

会社のオフィスにたとえると、こんなチーム編成です。

| 役 | 正体 | 会社でたとえると |
|---|---|---|
| 👤 **あなた** | 指示を出す人 | 部長 |
| 🤖 **Claude Code** | AI アシスタント | 派遣エンジニア |
| 📮 **Dispatcher GAS** | 窓口 GAS（HTTP API） | 受付窓口 |
| 📚 **GitHub（private）** | コード保管庫 + 接続情報の共有元 | 鍵付き書庫 |

### 1. あなた（ユーザー）

スプレッドシートの URL と「こういう GAS を書いて」という指示を送る人。作業の起点。

::: tip 部長の仕事
「やりたいこと」を日本語で伝えるだけ。コードの書き方も、ファイルの置き場所も、実行タイミングも、すべてアシスタント任せで OK。
:::

### 2. Claude Code

Anthropic の AI コーディングアシスタント。Web 版・スマホ版・デスクトップ版のどれを使っても結果は同じです。

受け取った指示から、シート構造を HTTP で読み、GAS コードを書いて、保存か実行か選び、エラーが出たらログを見て直すところまでやります。

::: tip 派遣エンジニアの仕事
「拡張機能 → Apps Script」の中身を自分で見て、必要に応じてコードを書き換え、動かし、結果を持ち帰って報告するところまで。
:::

### 3. Dispatcher GAS（窓口 GAS）

このガイドの**主役**。あなたの Google アカウントで 1 回だけ Deploy する中継 GAS です。

- 正体: `scripts/_dispatcher/Code.gs` を Apps Script として Deploy したもの
- 役割: Claude Code からの HTTP リクエストを受け取り、あなたの Google 権限で全スプレッドシートを操作する
- 設置場所: Google 側に 1 つだけ常駐（`script.google.com/macros/s/XXX/exec`）
- 認証: リクエストに含まれる `token` が Dispatcher 内の `SECRET_TOKEN` と一致すれば通す

::: tip 受付窓口の仕事
外部からの依頼を全部ここで受ける。身分証（トークン）をチェックして、OK なら社内の各部屋（シート）に依頼を取り次ぐ。あなた自身の権限で動くので、あなたが見えるシートは全部操作できる。
:::

### 4. GitHub（private リポジトリ）

書いた GAS コードのバックアップ先 + **Dispatcher の接続情報（URL とトークン）の共有元**。

`.claude/gas-dispatcher.json` というファイルをリポジトリにコミットしておくと、Claude Code のセッションが開かれた瞬間に環境変数へ自動展開されます。これで Web でもスマホでも、 **接続情報を毎回貼り直す必要がなくなります** 。

::: warning リポジトリは必ず private に
このファイルが読めれば誰でもあなたのシートを操作できます。public で運用する構成ではありません。
:::

::: tip 書庫の仕事
全書類に日付スタンプと変更理由を押して、過去のバージョンを 1 クリックで取り出せるよう整理しておく。加えて、通用口の鍵（URL とトークン）もここで管理して、社員（全端末の Claude Code）に自動配布する。
:::

## データの流れ

```
┌───────────────────────────────────────────────────┐
│ あなた                                            │
│  ↓「このシート URL、◯◯して」                   │
├───────────────────────────────────────────────────┤
│ Claude Code（Web / スマホ / デスクトップ）        │
│  ↓ HTTP POST + token                              │
├───────────────────────────────────────────────────┤
│ Dispatcher GAS（窓口、あなたの Google で実行）    │
│  ↓ SpreadsheetApp / DriveApp / ScriptApp          │
├───────────────────────────────────────────────────┤
│ 対象スプレッドシート + コンテナバインド GAS       │
└───────────────────────────────────────────────────┘
                ↑
                バックアップ + 接続情報の保管
                ↓
       GitHub（private リポジトリ）
```

ポイント:

- **あなたが操作するのは最初の「指示」だけ** 、以降は Claude Code が自動で進める
- Dispatcher は **1 ユーザーにつき 1 個** 。全シートを Dispatcher 経由で操作する
- 接続情報は **リポジトリ経由で端末間共有** 。`git clone` した瞬間に使える

## 使い捨て実行 vs 保存型

Claude Code は依頼の内容に応じて 2 つのモードを使い分けます。

| モード | エンドポイント | 保存されるか | 典型的な依頼 |
|---|---|---|---|
| **使い捨て実行** | `runScript` | ❌ | 「A 列を集計して教えて」「B シートの値を C に転記して」 |
| **保存型（コンテナバインド）** | `writeBoundScript` | ✅ 対象シートの「拡張機能 → Apps Script」に格納 | 「集計ロジックを保存して再利用」「メニューボタン付きで」「毎朝 9 時に自動実行」 |

::: tip 補足: コンテナバインド GAS とは
特定のスプレッドシートに紐付いた GAS で、そのシートを開いて「拡張機能 → Apps Script」から直接開けるやつです。引き継ぎやメニューボタンとの相性が良いので、このガイドでは保存型のデフォルトにしています。
:::

どちらを選ぶかは Claude Code が自動で判断しますが、明示的に「保存して」「使い捨てでいい」と指示することもできます。

## あなたが設定するもの、システムが自動でやること

| 項目 | 担当 | 頻度 |
|---|---|---|
| Dispatcher を Apps Script にデプロイ | あなた | **1 回だけ** |
| GitHub リポジトリ作成（テンプレートから）| あなた | **1 回だけ** |
| 接続情報ファイル（`.claude/gas-dispatcher.json`）のコミット | あなた | **1 回だけ** |
| 新セッションでの接続情報の読み込み | システム | 毎回自動 |
| GAS の作成・修正・実行 | Claude Code | 毎回自動 |
| GitHub へのバックアップ | Claude Code | 毎回自動 |
| エラー検知と自動修正 | Claude Code | 毎回自動 |

つまり、最初の **5 分の初期投資** を終えれば、以降はずっと「URL と指示を送るだけ」の世界が手に入ります。

## このシステムの強みと制約

### 強み

- **人間の作業が「指示を日本語で書く」だけ** に圧縮される
- Web 版 Claude やスマホからも等価に動く（認証ファイルのアップロード不要）
- 全変更が GitHub に履歴として残るので、安心して試行錯誤できる
- エラーが出ても Claude Code がログを見て自己修復する

### 制約

- Claude のサブスクリプションが必要（Pro / Max 相当）
- インターネット接続が必須
- Dispatcher は **あなたの Google 権限で動く** ので、その権限範囲を超える操作はできない
- リポジトリは private 前提（public にしたい場合は追加ローテ手順あり、[付録 C](/appendix/security)）
