# 第 1 章: 全体像

セットアップを始める前に、新方式の仕組みを 1 枚絵で頭に入れましょう。ここが分かっていると、あとで「どこで何を設定しているんだっけ？」と迷いません。

## 4 つの登場人物

| 役 | 正体 | たとえ |
|---|---|---|
| 👤 **あなた** | 指示する人 | 部長 |
| 🤖 **Claude Code** | AI アシスタント | 派遣エンジニア（Web / スマホ / デスクトップどれでも OK） |
| 📮 **Dispatcher GAS** | 窓口 GAS（HTTP API） | 受付窓口（全シートへの依頼を中継） |
| 📚 **GitHub（private）** | コード保管庫 + 認証情報の共有元 | 鍵付き書庫 |

ポイントは **Dispatcher GAS が 1 つだけあれば、全スプレッドシートを操作できる** ことです。シートごとに GAS を用意する必要はありません。

## データの流れ

```
┌─────────────────────────────────────────────────┐
│ あなた                                          │
│  ↓「このシート URL、◯◯して」                  │
├─────────────────────────────────────────────────┤
│ Claude Code（Web / スマホ / デスクトップどれでも）│
│  ↓ HTTP POST + token                            │
├─────────────────────────────────────────────────┤
│ Dispatcher GAS（窓口、あなたの Google で実行）  │
│  ↓ SpreadsheetApp / DriveApp / ScriptApp        │
├─────────────────────────────────────────────────┤
│ 対象スプレッドシート + コンテナバインド GAS     │
└─────────────────────────────────────────────────┘
                ↑
                バックアップ
                ↓
       GitHub (private、認証情報も保管)
```

- **あなた → Claude Code**: 日本語で「このシートの B 列を重複排除して」と頼む
- **Claude Code → Dispatcher GAS**: あらかじめ登録した URL へ、トークン付き HTTP POST でリクエスト
- **Dispatcher GAS → スプレッドシート**: あなたの Google 権限でシートを読み書き
- **結果**: Claude Code に JSON で返る → 必要ならコードや設定を GitHub にコミット

## 1 つの窓口で全部できる理由

Dispatcher GAS は「スプレッドシートを開く」「タブを読む」「セルを書く」「コードをコンテナバインドに保存する」「トリガーを張る」といった操作を、全て **URL を引数にして** 実行します。

そのため対象のスプレッドシートは:

- ✅ あなたの Google アカウントから見える
- ✅ 編集権限がある

この 2 つさえ満たしていれば、**追加で何かを紐づける必要はありません**。URL を渡した瞬間から操作可能です。

## 使い分け：使い捨て実行 vs 保存型

Dispatcher の機能には大きく 2 種類あります。どちらを使うかは Claude Code が判断してくれますが、感覚を掴んでおくと指示しやすくなります。

| 種類 | エンドポイント | 使いどころ |
|---|---|---|
| **使い捨て実行**（一度だけ動けばよい） | `runScript` | 「A 列を重複排除して B 列に出して」など、一回限りのバッチ処理 |
| **保存型**（シートに GAS を残す） | `writeBoundScript` | 「メニューに集計ボタンを追加」「日次更新関数を残す」など、継続的に使いたい機能 |

保存型では、対象スプレッドシートの「拡張機能 → Apps Script」を開けば、**Claude Code が書いたコードがそのまま見える** 状態になります。後から自分で手修正することもできます。

## スプレッドシートのコンテナバインド GAS

新方式では、保存型のコードは常に **そのスプレッドシートのコンテナバインド GAS** に格納されます。スタンドアロン GAS は以下のような例外時のみ使います。

- 複数スプレッドシートを横断する処理
- スプレッドシートに依存しないバッチ処理（BigQuery 直接操作など）
- 明示的に「スタンドアロンで」と指示した場合

基本は常にコンテナバインドなので、「シートを開いて拡張機能 → Apps Script」と辿れば対応コードに到達できます。

## 認証情報は GitHub に置きっぱなし

Dispatcher の URL とトークンは、リポジトリ内の `.claude/gas-dispatcher.json` にコミットしておきます。

```json
{
  "url": "https://script.google.com/macros/s/XXXXXXXX/exec",
  "token": "長いランダム文字列"
}
```

このファイルは **private リポジトリに置く前提** です。Claude Code は起動時にこのファイルを読み、環境変数 `GAS_DISPATCHER_URL` / `GAS_DISPATCHER_TOKEN` に自動展開します。

- ✅ Web Claude、スマホ Claude、デスクトップ Claude のどれで開いても即使える
- ✅ 新しい PC に切り替えても、リポジトリを clone すればそのまま動く
- ⚠️ リポジトリを **絶対に public にしない**（public 化時のローテ手順は [付録 C](../appendix/security) 参照）

これで全体像は OK です。次は実際に手を動かして環境を立ち上げましょう。
